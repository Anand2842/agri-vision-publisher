# ISSN Compliance Corrections

## Goal
Update the public website and admin controls to satisfy every correction in the ISSN authority’s email, using only verified official information and genuine publication files.

## Verified current gaps
- The website currently lists **Ram Mangalam Agri – Rural Development Foundation** as publisher, while the selected official publisher is **Dr. Dileep Kumar**.
- The archive currently contains only **Volume 1, Issue 1**.
- All seven published article records currently have no downloadable PDF; one also has no full website text.
- Editorial-board records support the requested details, but most displayed members are incomplete and the admin editor does not expose all required fields.

## Implementation

### 1. Editorial board compliance
- Expand the admin editor for editors, advisory members, and reviewers with:
  - official designation
  - department
  - institution
  - full official postal address
  - institutional email
  - official institutional profile URL
  - country and photo
- Improve the public Editorial Board page so every available official field is clearly and consistently displayed.
- Add validation and visible admin warnings for missing required fields, personal email domains, or non-institutional profile links.
- Import the verified board sheet once supplied.
- Remove or keep unpublished any member whose mandatory details cannot be verified; do not invent credentials or addresses.

### 2. Uniform publisher identity
- Replace RADF as the publisher with **Dr. Dileep Kumar** everywhere publisher identity appears, including About, Contact, footer, article metadata, certificates, policies, and structured search metadata.
- Use one exact official postal address everywhere, matching the corrected ISSN application.
- Keep editorial role and publisher role clearly distinguished.

### 3. Complete monthly archive
- Add direct cover and issue-PDF uploads to the admin Issues screen instead of requiring pasted URLs.
- Import each supplied genuine issue with its exact volume, issue number, publication date, cover, issue PDF, description, and article list.
- Check monthly ordering, archive filters, current-issue selection, issue table of contents, and downloads on phone and desktop.
- Do not create placeholder or backdated issues.

### 4. Full articles and downloads
- Add a clear compliance state in article administration showing whether each published article has website full text and a downloadable PDF.
- Upload the supplied full-text files and connect each to the correct article and issue.
- Keep only articles with genuine full text publicly published. Temporarily return incomplete abstract-only entries to draft until their complete files are supplied.
- Ensure every public article page shows readable full text and a prominent working PDF download.

### 5. Final compliance review
- Verify all board links and institutional emails, publisher wording/address, archive chronology, issue PDFs, article full text, and downloads.
- Test the public Editorial Board, About, Contact, Current Issue, Archives, and article pages on mobile and desktop.
- Review admin editing/upload flows and confirm the site builds without errors.
- Prepare a concise correction summary suitable for replying to the ISSN authority, listing the updated public links.

## Required source material
- The editorial-board sheet with verified official details.
- Dr. Dileep Kumar’s exact publisher postal address as written on the corrected ISSN application.
- All available issue covers, publication dates, article lists, and issue PDFs.
- The available full-text article files, with each file clearly matched to its article title.

## Technical notes
- Existing content remains managed through Lovable Cloud and the current admin area.
- Uploaded issue and article files will use the existing managed file storage and current access rules.
- No personal Gmail/Yahoo addresses will be presented as editorial-board institutional contacts.
